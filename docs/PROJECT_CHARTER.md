# Project Charter

## 1. Project Overview

IT Planning Workspace는 IT 기획 담당자가 반복적으로 수행하는 비용 분석, 정책 검색, 보고서 작성 등의 업무를 AI 기반으로 지원하는 의사결정 지원 플랫폼입니다.

본 프로젝트는 실제 IT Planning 업무를 기반으로 기획되었으며, AI를 활용하여 업무 효율성과 의사결정 품질을 향상시키는 것을 목표로 합니다.

---

## 2. Project Goal

- IT Planning 업무를 지원하는 AI 플랫폼 구현
- 실제 업무를 기반으로 한 기능 설계
- AI 활용 역량과 IT 기획 역량을 함께 보여주는 포트폴리오 제작

---

## 3. Scope

### In Scope

- 비용 데이터 분석
- AI 기반 비용 분석 및 인사이트 제공
- 정책 문서 검색(RAG)
- 보고서 초안 생성
- Dashboard

### Out of Scope

- 사용자 권한 관리
- 운영 환경 구축
- 대규모 트래픽 대응
- 실시간 협업 기능

---

## 4. Target User

- IT Planning 담당자
- IT 운영 담당자
- IT 관리자

---

## 5. Core Features

1. Cost Analysis Dashboard

비용 데이터를 업로드하면

- 비용 추이
- 서비스별 비용
- 이상 비용 탐지

를 제공합니다.

---

2. AI Decision Support

사용자가 질문하면

AI가 비용 데이터를 기반으로

원인 분석 및 개선 방향을 제공합니다.

---

3. Policy Search

사내 정책 문서를 검색하고

관련 내용을 AI가 요약하여 제공합니다.

---

4. Report Generator

비용 분석 결과를 기반으로

보고서 초안을 자동 생성합니다.

---

## 6. Success Criteria

- 모든 핵심 기능 구현
- GitHub 기반 프로젝트 관리
- 포트폴리오 제출 가능 수준 달성
